# Open Source Notes

This repository was prepared for public release with the following hygiene rules:

- no private dataset files are tracked;
- no build, install, debug, result or log directories are tracked;
- machine-specific absolute paths are replaced with `<dataset_root>`, `<output_root>`, `<model_root>` or `<repo>` placeholders;
- generated Doxygen HTML is ignored;
- public documentation explains that the code is a research prototype, not a production robotics stack.

Before adding new examples, prefer synthetic data or public datasets and document any license requirements.
